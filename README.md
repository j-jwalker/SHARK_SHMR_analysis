# SHARK_SHMR_analysis

Code related to my undergrad thesis relating to the SHARK Semi-Analytic Model. Code in this repository requires data_processing.py to run properly. Meant to be used on a specifically-formatted HDF5 file format. Code here written mostly by me but partially by Matias Bravo.

The code is extremely disorganized. One day maybe I'll come back in here and do something nice with it. Most of the code refrences data_processing.py in the repository to even work. But even then you need a very specific HDF5 file that only comes from SHARK.

The nicest plots from the project are on dexplots and MasterPlotter. The folder is full of csv files that are needed for some visualizations (in SHMR_plots, PresentationPlots, and a few others).
